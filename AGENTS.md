# Website work

Read WEBSITE_HANDOFF.md before changing this website. Use npm and keep the site static.

GitHub Pages publishes branch `new`, root `/`, to https://captaina1.com. Treat a push to `new` as publication. Do not publish unless the user requests live changes.

Check Git status and fetch before editing. Preserve unrelated work. Preview affected pages on desktop and mobile, run `npm run check` and `git diff --check`, and review the diff before committing. Verify the Pages deployment and live site after publishing.

Never print saved GitHub credentials or the Web3Forms access key. Do not submit enquiry forms unless the user expects test emails.

On Windows use `npm.cmd` if PowerShell script execution is blocked. Git HTTPS operations in Codex may need approved execution outside the restricted sandbox; test there before diagnosing a missing Git installation.
